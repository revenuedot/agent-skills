# AGENTS.md

The RevenueDot plugin for Claude, ChatGPT and Codex, plus its agent skills, installable with `npx skills add revenuedot/agent-skills`.

**The plugin is the folder `plugins/revenuedot/`.** People who install it get only that folder, and the Claude directory reads and scans only that folder. Keep it to plugin files: the manifests (`.claude-plugin/plugin.json`, `plugin.json` and its copy `.codex-plugin/plugin.json`, kept equal), `.mcp.json` and `mcp.json`, `skills/`, `assets/`, `evals/` (the `claude plugin eval` suite), the listing `README.md` and `LICENSE`. Never put tests, shell scripts, code or build notes in it, and never name an image file there except in the README's Markdown image syntax and the manifests' icon fields. Everything else stays at the repository root: `test/`, `scripts/`, `submission/`, `.github/`, the root `README.md` for GitHub visitors, and the marketplaces `.claude-plugin/marketplace.json` (Claude Code) and `.agents/plugins/marketplace.json` (Codex), which both point at `./plugins/revenuedot`. Raise `version` in all three manifests with every release.

Each skill is `plugins/revenuedot/skills/<name>/SKILL.md` with YAML frontmatter: `name` (equal to the folder name), `description` (one or two sentences starting "Use this skill when ..."), and `license: MIT`. List every skill in both READMEs. A skill never prints a `${...}` reference to a credential variable or puts a credential-named variable on the same line as a URL, because the directory's scanner reads that as sending a credential from the user's machine.

Every command, flag, environment variable, URL path and code line in a skill must match the current code in `revenuedot/revenuedot` (server, importer), `revenuedot/examples` and `revenuedot/mcp`. Check it against the source or a running server before merging, and remove anything that does not exist. Record decisions in files and commit them. Private material goes to `revenuedot/company`, never here.

Check with `node --test test/*.mjs`, `claude plugin validate plugins/revenuedot --strict` and `claude plugin validate . --strict`. Build the ChatGPT upload ZIP with `scripts/pack-openai.sh`; it zips from the plugin folder and leaves out the `migrate-from-revenuecat` and `self-host` skills and `evals/`.
