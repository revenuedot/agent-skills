# RevenueDot agent skills

**Skills that teach coding agents (Claude Code, Codex, Cursor) to set up RevenueDot and migrate an app from RevenueCat.**

> Status: pre-alpha. Nothing is ready to use yet.

Planned skills:
- `migrate-from-revenuecat`: point the RevenueCat SDK at RevenueDot, run the importer, set up notification forwarding for a dual-run, then switch to the RevenueDot SDK.
- `add-subscriptions`: add in-app purchases and a paywall to an iOS, Android, React Native or Flutter app with RevenueDot.
- `self-host`: run RevenueDot with Docker.

RevenueDot is not affiliated with RevenueCat, Inc.
